# 通用上帝圖靈機 v4.5：通用性範圍

## 機器模型

UGTM v4.5 實作 Brainfuck-8 解譯器，支援完整八指令：

| 指令 | 語義 |
| --- | --- |
| + / - | 目前儲存格以模 256 加一或減一 |
| > / < | 讀寫頭向右或向左移動 |
| . | 輸出目前儲存格的位元組 |
| , | 讀取一個輸入位元組；輸入耗盡時寫入零 |
| [ / ] | 依目前儲存格是否為零進行配對跳躍 |

帶以整數位置至 8-bit 儲存格的稀疏映射表示，允許讀寫頭向兩側移動。跳躍表在執行前建立，並檢查每個左括號都有配對。

## 已執行驗證

- 閉合程式 ++++++++[>++++++++++<-]>+++. 輸出 S。
- 輸入程式 ,. 在輸入 A 時輸出 A。
- Z-combinator 提供解譯步驟函數的遞迴固定點。
- 實盤交易保持停用。

## 通用性主張

在「帶可無界延伸、執行時間與儲存空間不設有限上限」的理想模型下，此解譯器涵蓋所指定 Brainfuck-8 模型的完整指令語義。其通用性繼承自該模型的圖靈完備性。

實際 Python 程序受到遞迴深度、記憶體與執行時間限制。因此，倉庫中的有限執行檔是通用模型的實作原型，不是能在有限硬體上完成所有無限計算的機器。

## 未宣稱的命題

本實作不構成一般克萊尼第二遞迴定理的形式化證明，不證明 Church–Turing 同構，也不是純 λ 演算。它不解決停機問題、哥德爾不完備性或其他一般不可判定問題。
